# Linux Server From Scratch

A hands-on Linux server administration project built from a fresh Debian Linux installation.

The goal of this project is to build, configure, secure, automate, and document a Linux server from the ground up while developing practical Linux system administration skills.

## Project Goals

* Install and configure a Linux server from scratch
* Understand Linux system administration in a practical environment
* Configure users, groups, permissions, and privilege management
* Configure networking and remote administration
* Secure the server using firewall and SSH hardening
* Deploy and configure a web server
* Manage services using systemd
* Implement logging, monitoring, and health checks
* Automate backups and routine administrative tasks
* Document configuration decisions, troubleshooting, and verification

## Technology

* Debian Linux
* VMware Workstation Pro
* OpenSSH
* Nginx
* systemd
* nftables / firewall tooling
* Bash
* Git and GitHub
